# 采购计划规则

本文档记录当前库存日报和网页采购计划使用的计算口径。

## 1. 计算粒度与数据范围

采购计划以“仓库 + SKU”为一条记录，分别计算每个仓库中的每个 SKU。

主要使用以下数据：

- 近 3 日、近 7 日、近 30 日销售出库量
- 可用库存
- 采购在途
- 其他仓可调拨库存
- 供应商
- 生产周期
- 最低起订量
- 商品结构和 SKU 基础资料
- 产线和日产能（来自旺店通货品规格的 `prop4`、`prop5`，用于采购观察）

采购计划日报和页面只计算以下五个启用销售仓：

- 主仓库（新）
- TMT康复仓
- 杰菲克德国仓
- 日本仓
- ENYISA仓

五个仓库中的启用且非清仓 SKU 都保留在列表中。已经明确配置为“清仓款”的 SKU 不在采购计划中显示；没有生产周期的 SKU 仍会列出，但不计算下单日、不计算采购量、不着色。

以下货品不参与正常采购量计算：

- 清仓款
- 赠品、运费、寄付、差价等非正常销售链接
- 被停用或非销售角色仓库中的库存

## 2. 日销量预测

当近 30 日有完整销售历史时，先计算基础日销量：

```text
7日日均销量 = 近7日销量 ÷ 7
30日日均销量 = 近30日销量 ÷ 30
基础日销量 = 7日日均销量 × 40% + 30日日均销量 × 60%
```

如果历史不足 30 日，则依次使用近 7 日平均、近 3 日平均或当前有效日期平均。

## 2.1 公式分类映射

Excel 将产品类型写成“基础款/放大款/测款 + 护腕/护膝/护踝/护腰/其他”。系统将旺店通的详细 `category` 映射为：

```text
包含“护腕” → 护腕
包含“护膝” → 护膝
包含“护踝” → 护踝
包含“护腰” → 护腰
其他所有分类 → 其他
```

产品结构仍单独读取 SKU 的产品结构字段，不能只依靠 `category` 判断基础款、放大款或测款。

## 3. 趋势系数

趋势系数比较的是两个时间段的“日均销量”，不是直接比较 7 日总销量和 30 日总销量：

```text
趋势系数 = 7日日均销量 ÷ 30日日均销量
```

等价写法：

```text
趋势系数 =（近7日销量 ÷ 7）÷（近30日销量 ÷ 30）
```

例如近 7 日销量 70、近 30 日销量 300：

```text
7日日均 = 10
30日日均 = 10
趋势系数 = 1
```

趋势系数不是增长率，只表示近期日销量相对于 30 日日均的比例。

趋势倍率只作用于采购数量，不再二次调整日销量。日销量用于库存覆盖天数和下单时间；趋势倍率用于采购目标库存量。

采购趋势倍率规则：

| 趋势系数 | 采购倍率 |
| ---: | ---: |
| 小于 0.5 | 0.5 |
| 0.5 至小于 0.8 | 0.6 |
| 0.8 至小于 1.2 | 1.0 |
| 1.2 至小于 1.8 | 1.2 |
| 大于等于 1.8 | 1.4 |

近 7 日和近 30 日存在时间重叠，因此该系数用于平滑调整，不是短期增长率。

## 4. 库存供给与库存覆盖

用于判断到货前是否缺货的供给量为：

```text
供给量 = 可用库存 + 采购在途
```

可用库存、采购在途和跨仓调拨只用于库存覆盖、缺货风险和下单时间判断，不参与扣减采购数量。

含在途库存覆盖天数：

```text
含在途库存天数 =（可用库存 + 采购在途）÷ 预测日销量
```

页面和日报中覆盖天数按四舍五入显示为整数。

## 5. 生产周期与下单日期

普通供应商的到货周期为：

```text
到货周期 = 生产天数 + 提前天数
```

提前天数规则：

| 生产天数 | 提前天数 |
| ---: | ---: |
| 15 天 | 2 天 |
| 25 天 | 3 天 |
| 30 天 | 5 天 |
| 其他 | 生产天数 ÷ 6，至少 1 天 |

宏博/铠博（兼容历史名称“博凯”）基础款规则：

- 生产天数未配置时，默认 30 天。
- 只有供应商为宏博、铠博或博凯且商品结构为“基础款”时，才显示每月 5 日或 20 日的固定下单日参考。
- 额外包含 5 天物流/预留时间。
- 默认到货周期为 `30 天生产 + 5 天提前 + 5 天物流/预留 = 40 天`。
- 理论下单日始终先按库存倒推，不使用固定日改写紧急程度。
- 每月 5 日、20 日只作为采购人员的执行参考；如果库存已经进入完整交付周期以内，则忽略固定日并紧急排单。
- 其他供应商的基础款按每周四下单。
- 放大款、测款不使用固定日期，按库存天数阈值触发：生产 15–20 天时低于 20 天，25 天时低于 30 天，30 天时低于 35 天。

理论下单日：

```text
理论下单日 = 预计缺货日 - 完整交付周期
```

紧急缺货采用严格小于边界：

```text
含在途库存天数 < 完整交付周期
```

例如完整交付周期为 40 天：

- 50 天库存：非紧急，按理论日期排期。
- 40 天库存：非严重缺货，但已经到达近期下单边界。
- 39.99 天库存：紧急缺货，红色预警。

## 6. 预计缺货与采购目标量

含在途库存覆盖天数用于推算预计缺货日：

```text
预计缺货日 = 统计结束日 + 向上取整的含在途库存天数 - 1 天
```

Excel 下单公式以周销量 A 为基础。A 定义为近 7 日销量总量，不是日均销量。

目标库存量：

| 生产周期 | 目标库存公式 |
| ---: | ---: |
| 15–20 天 | 2A + 2A = 4A |
| 25 天 | 4A + 3A = 7A |
| 30 天 | 4A + 4A = 8A |

采购目标量：

```text
采购目标量 = 目标库存量 × 趋势倍率
```

计算采购量基础值：

```text
计算采购量基础值 = 采购目标量
```

采购数量不再扣减可用库存、采购在途或建议调拨。上述供给数据只影响库存覆盖天数、预计缺货日、紧急程度和建议下单日。

## 7. 最低起订量

- 已配置起订量时，使用 SKU 的配置值。
- 起订量未配置时，默认按 100 件。
- 明确配置为“无”时，保留为无最低起订量，不强制补到 100 件。

默认 100 件是采购计算规则，不会自动改写 SKU 基础资料中的起订量字段。

## 8. 采购量取整

先对采购目标量向上取整数：

```text
计算采购量 = 采购目标量向上取整
```

当计算采购量低于最低起订量时：

```text
建议下单量 = 最低起订量
```

当计算采购量达到最低起订量后，按 50 件倍数取整：

| 计算采购量 | 建议下单量 |
| ---: | ---: |
| 103 | 100 |
| 109 | 100 |
| 111 | 150 |
| 238 | 250 |

规则为：

- 余数 1 至 10：向下取到下一个 50 的倍数
- 余数 11 至 49：向上取到下一个 50 的倍数

低于最低起订量的情况是例外：先补足最低起订量，不直接按 50 件倍数破坏起订量规则。

## 9. 低销量观察

同时满足以下条件时，标记为“低销量观察（清仓候选）”：

```text
近30日有销量
趋势系数 < 0.5
预测日销量 < 1
```

这类 SKU 会保留在采购计划中供运营查看，但建议下单量改为 0，不会因为最低起订量而强行采购。

## 10. 展示范围、提前排单与颜色

系统会提前展示未来 7 天内计算出的下单计划，并同时保留五仓全部启用且非清仓 SKU，按建议下单日排序。

日报行颜色含义：

- 红色：含在途库存天数严格小于完整交付周期，建议紧急排单。
- 黄色：未来一周内下单。
- 蓝色：一周以外的后续排期。
- 紫色：低销量清仓候选，建议下单量为 0。
- 缺生产周期：只展示基础数据，不计算、不着色。

计算量低于最低起订量而被补足时，只给“起订量补足”单元格单独标色，便于采购人员确认。

## 11. 条数与件数

采购计划中的“条数”是仓库-SKU记录数，不是采购件数。

例如：

- 83 条计划，表示有 83 个仓库-SKU组合进入列表。
- 其中部分可能是“低销量观察”，建议下单量为 0。
- 实际采购件数应查看“建议下单量”合计。
